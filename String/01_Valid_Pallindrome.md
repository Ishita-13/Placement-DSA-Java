# Valid Palindrome

## Difficulty
Easy

## Pattern
Two Pointers

## Key Idea
Compare characters from both ends.

## Approach
Ignore spaces, symbols and case.
Compare `left` and `right` characters.

## Time Complexity
O(n)

## Space Complexity
O(1)

## Key Trick
Left → Right
Right → Left
